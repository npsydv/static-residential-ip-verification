## 先搞清楚：你买的“静态”是哪一种

市面上标“静态住宅”的东西至少有三种，价钱差好几倍，坑基本都在这。

**第一种，真静态住宅。** IP 固定，ASN 归属民用宽带运营商。两个条件缺一不可：出身是民宅，地址不轮换。

**第二种，长效静态。** IP 固定是真的，但线路在机房或城域网，“住宅”这半截是缺的。不少平台直接把它标成静态住宅，你拿到手一查 ASN 是 hosting。这不算骗，是口径不同，但用来养号就是另一回事。

**第三种，“静态”指的是会话保持（Sticky Session）。** 底层还是动态池，到期换 IP。做采集够用，养号会出事：账号登录到第三周突然换了城市，风控立刻标记。

分辨方法不用看页面文案，问客服三句话：这条 IP 的 ASN 是 ISP 还是 IDC？租期内 IP 会不会变，变了算不算违约？独享还是共享，同一时段这个 IP 有没有别人在用？

“静态住宅 IP 的价格差异主要来自 IP 资源的稀缺性而非带宽。真实民宅线路每条宽带能分配的 IP 数量极少，扩容必须真实装机，所以静态住宅 IP 的月付价格通常是同带宽机房 IP 的 2–5 倍。”这句话反过来也成立：看到“住宅 IP”卖得比机房 IP 还便宜，先去查 ASN。

## 4 步验真法：10 分钟筛掉机房套壳

**第 1 步，查 ASN 归属，一票否决。** 打开 ipinfo.io 输入 IP，或去 bgp.he.net 查 IP 段，看 ASN owner 是谁。

| 查到的结果 | 含义 | 判定 |
| --- | --- | --- |
| AT&T / Comcast / Verizon / 中国电信 / 中国联通 / 中国移动 | 民用宽带运营商 | 真住宅出身 |
| Amazon / Google Cloud / DigitalOcean / 阿里云 / Vultr | 云厂商 | 机房 IP |
| 各类 IDC、Hosting、Data Center 字样的公司 | 数据中心 | 机房 IP |
| 小型区域 ISP，但 IP 段标注 hosting | 混合 | 需第 2 步复核 |

这一条能筛掉市面上大部分“静态住宅”。很多所谓住宅 IP，ASN 一查就是 IDC。

**第 2 步，查类型库。** ipapi.is 或 ip-api.com 看 type 字段（residential / hosting / proxy），IP2Location 看 usage type（ISP / DCH / SES），Scamalytics 看 fraud score。判定标准：三个库里至少两个标为 residential 或 ISP，且 fraud score 低于 25。

**第 3 步，查黑名单与滥用记录。** AbuseIPDB 看举报次数和最近一次举报时间，Spamhaus ZEN、SpamCop 这些 DNSBL 也过一遍。近 90 天无举报、主流黑名单零命中才算过。IP 出身真不等于 IP 干净，上一个用户要是拿它刷过单，你接手就是脏 IP。买之前问一句能不能指定“未被使用过的新 IP”。

**第 4 步，查 DNS 与 WebRTC 泄漏、时区一致性。** browserleaks.com/webrtc 和 ipleak.net 各跑一次，重点看 DNS 解析结果落在哪个国家、WebRTC 有没有暴露真实出口、浏览器时区和 IP 归属地是否一致。

> **判定卡**：第 1 步 ASN = ISP（非 hosting），一票否决；第 2 步三个类型库至少 2 个标 residential，缺则降级；第 3 步黑名单零命中、90 天无举报，影响存活率；第 4 步 DNS/WebRTC 不泄漏、时区语言一致，影响封号率。四步全过可以用于养号，缺 1 条就只适合采集。

## 两个让 IP 白买的配置错误

**DNS 泄漏。** IP 换成洛杉矶了，DNS 还在本地解析，目标网站拿到的是你的真实位置。用 ipleak.net 看 DNS 解析结果落在哪个国家，客户端开远程 DNS，或者在 SOCKS5 里直接让代理端解析。

**WebRTC 泄漏。** 浏览器会绕过代理直连 STUN 服务器拿本机地址，IP 显示得再干净也没用。用 browserleaks.com/webrtc 测，处理方式是禁用 WebRTC 或屏蔽 3478、19302 端口。

还有一个常被忽略的：一条 IP 同时登多个账号，还以为“IP 干净就行”。设备指纹（Canvas、字体、WebGL）、Cookie、操作节奏都参与关联判定。一个账号一条独立 IP 是安全做法，尤其电商店铺；社媒养号有人一条 IP 挂 3–5 个低关联账号，那是经验值，不是安全保证。
